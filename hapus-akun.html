Hapus Akun dan Data

Aplikasi: Prompt Builder (Android)

Halaman ini menjelaskan cara meminta penghapusan akun Prompt Builder beserta data yang terkait denganmu.

Cara meminta penghapusan

  1. Buka aplikasi email dari alamat email yang sama dengan akun Google yang kamu pakai untuk masuk ke Prompt Builder.
  2. Kirim email ke vid1hihu@gmail.com dengan subjek Hapus Akun Prompt Builder.
  3. Di isi email, tulis: "Saya meminta penghapusan akun dan seluruh data saya di Prompt Builder."
  4. Kami akan membalas untuk mengonfirmasi, lalu menghapus akunmu. Proses selesai paling lama dalam 30 hari setelah permintaan diterima.

Kamu juga dapat berhenti memakai aplikasi kapan saja dengan mencopot aplikasi dari perangkat. Mencopot aplikasi menghapus data lokal di perangkat, tetapi tidak menghapus data di akun cloud; untuk itu, kirim permintaan seperti di atas.

Data yang dihapus

DataKeterangan
Informasi akunAlamat email dan ID akun
Konten tersimpan di cloudRiwayat prompt, simpanan, halaman tersimpan, pengaturan
Data pemakaianKuota harian, statistik dan log pemakaian

Kunci API pribadiJika pernah kamu masukkan dan tersinkron ke akun

Data yang mungkin disimpan

  • Catatan transaksi pembayaran yang wajib disimpan untuk pembukuan atau kewajiban hukum dapat disimpan sesuai ketentuan yang berlaku, dan tidak dipakai untuk tujuan lain.
  • Data yang sudah dikirim ke penyedia layanan pihak ketiga (misalnya layanan AI) tunduk pada kebijakan masing-masing penyedia.
