Untuk fitur generate JSON prompt via AI, tools ini perlu disambungkan ke Google AI. Gratis dan hanya perlu dilakukan sekali.

3
Klik tombol "Create API Key"

4

Kode panjang diawali AIza... atau AQ....

Pilih Angle
Overhead / Flat Lay Dari Atas 90°

45° Angle Natural
Sudut 45° dari atas — tampilkan sisi atas dan depan produk sekaligus. Paling natural dan sering dipakai untuk produk apapun.
Front Facing Sejajar Produk
Kamera sejajar produk, menghadap langsung ke depan — cocok untuk produk dengan label atau detail depan yang ingin ditonjolkan.
3/4 View Editorial
Sudut 3/4 — tampilkan depan dan sisi produk sekaligus. Memberi kesan volume dan dimensi. Cocok untuk tas, sepatu, kotak produk.
Dipegang Tangan Ada Tangan

Pilih Angle
Low Angle Dari Bawah

High Angle Dari Atas

Cara Pakai

  
Baca sekali, pakai berkali-kali.

  
1
Tab Foto — Pilih Foto Referensi
Klik tipe foto yang kamu punya (Wajah, Outfit, Produk, dll). Bisa lebih dari satu. Preview thumbnail otomatis muncul di atas.

  
2
Tab Foto — Produk Otomatis Terdeteksi
Kalau kamu pilih "Foto Produk" di step 1, step produk otomatis dilewati. Kalau tidak ada, baru ditanya.

  
3
Generate → Salin → Paste
Output JSON Full (detail) atau Compact. Paste prompt ke Google Flow.

  

  
Cara Pakai — Tab Video

  
1
Pilih Mode Referensi Foto
Mode 1 = satu foto dipakai untuk karakter, outfit, dan lokasi sekaligus. Mode 2 = pakai aset frame awal. Mode 3 = karakter, produk, dan lokasi diatur terpisah (paling detail).

  
2
Atur Suara Karakter
Isi jenis kelamin & usia, nada bicara, lalu aksen/logat — ini menentukan gaya suara di voice_character pada JSON hasil akhir.

  
3
Pilih Cara Bikin Script
Dibantu AI — isi nama produk & target audience, AI buatkan 3 script (Hook/Cerita/CTA) otomatis. Tulis Manual — kamu ketik sendiri ketiganya. Banyak Produk Sekaligus — generate sampai 10 produk (30 script) dalam satu proses, cocok kalau kamu jualan banyak SKU.

  
4
Edit & Salin JSON
Tiap script bisa diedit langsung di kartu hasil — JSON di bawahnya ikut update otomatis tiap kamu ketik. Salin, paste ke Veo 3 / Google Flow.

  

  
Tips Penting

  

    

       Wajah + Outfit + Produk = kombinasi terbaik untuk hasil paling akurat

       Step produk otomatis muncul jika kamu tidak pilih foto produk

       Nama produk spesifik = hasil AI lebih akurat dan konsisten

       Compact JSON kadang lebih baik jika foto referensi banyak

       Tab Video — script AI otomatis dibatasi 25 kata biar pas untuk durasi video, tapi tetap bisa diedit manual di kartu hasil
